# Cybersecurity Journey

This repository documents my hands-on cybersecurity learning journey covering Linux fundamentals, networking, Python for security, offensive and defensive security, TryHackMe progress, certifications, and practical projects.

## Structure

- `00-career-development/` — career planning, resume, interview prep, and job tracking
- `01-linux-fundamentals/` — Linux commands, permissions, processes, packages, and filesystem
- `02-networking-fundamentals/` — networking concepts, protocols, DNS, HTTP, troubleshooting
- `03-python-for-cybersecurity/` — Python basics and practical security scripts
- `04-tryhackme/` — room progress and learning path notes
- `05-offensive-security/` — recon, web security, and lab reports
- `06-defensive-security/` — logs, IR, detection, threat intelligence
- `07-soc-and-security-monitoring/` — SIEM, Wireshark, and monitoring notes
- `08-certifications/` — study notes and certification prep
- `09-practical-projects/` — applied security projects
- `10-security-notes/` — quick references and glossary
- `11-resources/` — learning platforms and tools

## Goals

- Build foundational cybersecurity knowledge
- Learn practical Linux and networking skills
- Practice through labs and writeups
- Track progress over time
- Maintain a personal security knowledge base
