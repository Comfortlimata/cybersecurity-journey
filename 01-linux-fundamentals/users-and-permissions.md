# Users and Permissions

## User account basics

- `whoami` — current user
- `id` — user and group information
- `sudo` — run command with elevated privileges

## File permissions

```bash
ls -l
chmod 755 script.sh
chown user:user file.txt
```

## Permission bits

- `r` = read
- `w` = write
- `x` = execute

## Linux groups

Users may belong to groups that affect access control and privileges.
