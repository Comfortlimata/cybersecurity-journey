# Networking Commands

## Useful networking commands

- `ip a` — network interfaces
- `ip route` — routing table
- `ping` — connectivity test
- `curl` — retrieve URLs
- `netstat` — network connections
- `ss` — socket statistics
- `nslookup` / `dig` — DNS lookup

## Example

```bash
ip a
ping 8.8.8.8
curl -I https://example.com
ss -tulpn
```
