# Linux Commands

## Essential commands

- `ls` — list files and directories
- `pwd` — print working directory
- `cd` — change directory
- `cp` — copy file
- `mv` — move or rename file
- `rm` — remove file
- `mkdir` — create directory
- `cat` — display file contents
- `grep` — search text
- `find` — locate files
- `top` / `ps` — view running processes

## Example usage

```bash
ls -la
pwd
grep -R "error" /var/log
ps aux
```
