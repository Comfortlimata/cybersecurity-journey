# Career Roadmap

## Objective

Plan a structured path from beginner to professional cybersecurity roles.

## Suggested Roadmap

1. Linux fundamentals
2. Networking fundamentals
3. Python for automation and security
4. TryHackMe / labs
5. Offensive and defensive skills
6. Certifications and practical projects
7. Job preparation and portfolio building

## Milestones

- Foundation: Linux, networking, scripting
- Intermediate: security tools, web exploitation, SIEM
- Advanced: incident response, threat detection, home lab
- Career readiness: portfolio, resume, interview prep
